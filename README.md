# 🌤️ SkyCast – Weather Application

A modern and responsive weather application that allows users to search for any city and view current weather conditions, hourly forecasts, and a 5-day weather forecast.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature and feels-like temperature
- 💧 Show humidity, wind speed, and cloud cover
- 🌅 Display sunrise and sunset times
- 🕒 Hourly weather forecast
- 📅 5-day weather forecast
- 📱 Responsive design for different screen sizes
- 🌍 Automatic location-based timezone support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Srushti0611/Weather-app.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🌐 API Used

This project uses the free [Open-Meteo API](https://open-meteo.com/) to fetch weather and location data.

**Note:** No API key is required.
